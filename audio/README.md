# Распознавание речи

Небольшая программа на Python, которая преобразует аудио в текст с помощью модели **Whisper** от OpenAI.

Программа автоматически использует GPU, если доступна CUDA, иначе работает на процессоре.

## Установка

```bash
pip install torch transformers
```

Для работы с MP3 также может понадобиться `ffmpeg`.

## Запуск

Положить аудиофайл `sample.mp3` рядом с `main.py` и запустить:

```bash
python main.py
```

После обработки программа выведет распознанный текст

Используется готовая модель `openai/whisper-small`, поэтому самостоятельно обучать её не нужно.
