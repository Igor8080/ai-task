# Определение тональности текста

Небольшая программа на Python, которая определяет тональность текста с помощью готовой модели из библиотеки Transformers.

Модель определяет, является ли текст положительным, отрицательным или нейтральным.

## Установка

```bash
pip install transformers torch
```

## Запуск

```bash
python main.py
```

Программа проверяет несколько примеров текста и выводит результат и уверенность модели:

```text
Текст: Мне нравится этот трек.
Тональность: POSITIVE
Уверенность: 97.86%
```

Для работы используется готовая модель `blanchefort/rubert-base-cased-sentiment`, поэтому обучать модель самостоятельно не требуется.
