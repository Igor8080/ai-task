# Классификация изображений

Небольшая программа на Python, которая определяет, что изображено на картинке, с помощью готовой модели **ResNet50** из PyTorch.

## Установка

Установить необходимые библиотеки:

```bash
pip install torch torchvision pillow
```

## Запуск

Положить изображение `sample.jpg` рядом с файлом `main.py` и запустить:

```bash
python main.py
```

Программа выведет 5 наиболее вероятных классов и вероятность каждого из них
```

Модель уже обучена на ImageNet, поэтому дополнительно обучать её не нужно.
