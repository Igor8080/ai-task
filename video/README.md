# Распознавание объектов на видео

Небольшая программа на Python, которая распознаёт объекты на видео с помощью готовой модели **DETR**.

Для каждого найденного объекта программа рисует рамку и показывает его название и уверенность модели. Результат сохраняется в отдельный видеофайл.

## Установка

```bash
pip install torch transformers opencv-python pillow
```

## Запуск

В `main.py` нужно указать пути к исходному и итоговому видео:

```python
VIDEO_PATH = "D:\\ing\\video\\sample.mp4"
OUTPUT_PATH = "D:\\ing\\video\\output.mp4"
```

После этого запустить:

```bash
python main.py
```

Результат будет сохранён в файл `output.mp4`.

Для распознавания используется готовая модель `facebook/detr-resnet-50`, поэтому дополнительно обучать её не требуется.
